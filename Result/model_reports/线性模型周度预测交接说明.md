# 线性模型周度预测交接说明

## 1. 推荐保留的三个候选

本轮比较覆盖旧版筛选、不同相关性上限、不同综合排名权重以及方向调整实验。综合考虑样本外收益、Sharpe、Rank IC、ICIR、最大回撤、换手率和分年度稳定性，建议下一阶段只重点保留以下三个互补候选。

| 定位 | 实验与模型 | 年化收益 | Sharpe | 平均 Rank IC | 年化 ICIR | 最大回撤 | 平均单边换手 |
|---|---|---:|---:|---:|---:|---:|---:|
| 主候选：收益与风险调整后表现最好 | Corr 0.50 + Ridge | 7.24% | 0.752 | 0.0268 | 1.186 | -10.16% | 60.38% |
| 低换手候选：收益接近主候选、换手更低 | Corr 0.85 + Elastic Net | 7.11% | 0.741 | 0.0244 | 1.076 | -9.97% | 45.53% |
| 信号候选：Rank IC 和 ICIR 最高 | 旧版筛选 + Elastic Net | 5.55% | 0.587 | 0.0322 | 1.440 | -9.43% | 59.51% |

选择理由：

- `Corr 0.50 + Ridge` 的年化收益和 Sharpe 均为当前最高，且 2024、2025、2026 三个测试年度收益均为正，作为主候选。
- `Corr 0.85 + Elastic Net` 的收益和 Sharpe 与主候选非常接近，但平均换手显著更低，适合作为考虑真实交易成本后的候选。
- `旧版筛选 + Elastic Net` 的 Rank IC 和年化 ICIR 最高，虽然 2025 年组合收益为负，仍值得作为纯预测信号候选保留。
- Corr 0.50 下的 OLS 与 Ridge 结果几乎相同，不单独保留，避免候选冗余。

## 3. 推荐读取方式

```python
from pathlib import Path
import pandas as pd

# 从仓库根目录运行；若从其他目录调用，请把这里改为仓库根目录。
project_root = Path.cwd()

prediction_path = (
    project_root
    / "Result/model_reports/linear_development_oldscreen_corr050/oos_predictions.parquet"
)

predictions = pd.read_parquet(prediction_path)
weekly_scores = predictions.loc[
    predictions["model_name"].eq("ridge"),
    [
        "signal_date",
        "execution_date",
        "wind_code",
        "prediction",
        "prediction_rank",
        "prediction_z",
        "model_name",
        "model_id",
        "fold_id",
        "train_end_date",
    ],
].copy()

weekly_scores = weekly_scores.sort_values(["signal_date", "wind_code"])
```

下游选股或组合优化建议优先使用 `prediction_rank`。它是每个信号日内部的股票截面百分位排名，范围为 0–1，比不同年度、不同滚动模型产生的原始 `prediction` 更容易统一使用。如果下游模型需要有正负方向和相对强度，可使用 `prediction_z`。

## 4. 预测文件字段

| 字段 | 含义 |
|---|---|
| `signal_date` | 周度信号形成日，当周最后一个实际交易日 |
| `execution_date` | 下一交易日执行日期 |
| `target_end_date` | 本周预测收益对应的结束日期 |
| `wind_code` | 股票代码 |
| `prediction` | 模型原始预测值 |
| `prediction_rank` | 当周截面百分位排名，范围 0–1 |
| `prediction_z` | 当周截面标准分，截断在 [-3, 3] |
| `model_name` | `ridge`、`elastic_net`、`lasso` 或 `ols` |
| `model_id` | 配置对应的可追溯模型标识 |
| `fold_id` | 样本外测试年份 |
| `train_end_date` | 该折训练标签的最晚结束日期 |
| `data_mode` | 当前文件为 `development` |

任务说明要求的最小字段 `signal_date`、`execution_date`、`wind_code`、`prediction`、`model_name`、`fold_id` 已全部包含。

当前三个文件的预测期均从 2024-01-05 开始，至 2026-09-24，合计 141 个周度信号日。2026 年是截至数据末日的非完整年度。

## 6. 使用限制

1. 当前结果的 `data_mode` 是 `development`，股票池为当周存在行情的股票，并非逐历史时点的真实中证 A500 成分股，因此不能直接称为正式 A500 样本外结果。
2. 正式交付前需要提供历史 A500 成分股快照，用相同配置重新运行并生成 `official` 预测文件。
3. 本轮已经查看并比较了 2024–2026 测试结果，因此三个候选属于探索性筛选结果。最终定型应使用新的时间段或未参与本轮筛选的数据确认。
4. 预测文件中同时保存了实际收益、价格和标签字段，交给下游同学时建议只读取第 3 节列出的预测及追溯字段，避免误用未来实现收益。
5. 三个候选可以分别进入下游组合优化，不建议再根据同一测试期收益对其做二次调参。
