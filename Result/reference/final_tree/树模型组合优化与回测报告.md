# 树模型分数版：组合优化与回测报告

> 本报告记录将**因子经 LightGBM 树模型训练后的预测分数**（`prediction_rank`，0-1 截面排名分，训练细节见同目录《树模型训练报告》）接入本地组合优化与回测管线的全部步骤与结果。管线参数与线性模型分数版（`final/`）**完全一致**，唯一区别是输入分数来源；两边回测窗口完全相同（133 周），可直接对比。所有代码与产物位于 `final_tree/` 目录。

---

## 0. 总体流程

```
树模型样本外预测（141 周 × 500 只，prediction_rank）
        │  prepare_tree_scores.py（周频对齐 + 防前视映射 + 同周去重）
        ▼
predictions_tree.parquet（pred_week, feature_dt, securityID, stacking）
        │
        ├─ portfolio_opt_v1_tree.py  →  v1 四组合：BL / 风险约束BL / MV / 等权
        ├─ portfolio_opt_v2_tree.py  →  v2 MV+约束组合（行业中性 + 换手惩罚）
        └─ portfolio_opt_v3_tree.py  →  v3 BL+约束组合（BL 后验 + 同 v2 约束）
        │
        ▼
backtest_tree.py（六组合统一回测：周收益 → 换手 → 扣成本费用 → 指标 → 图）
        │
        ▼
指标表、净值图、超额图、月度胜率图、换手柱状图、分年度业绩表、与线性版对比图
```

## 2. 预测分数准备（prepare_tree_scores.py）

**周编号映射（与线性版完全相同的口径）：**

- 价格面板第 i 个交易日属于第 `i//5+1` 个 5 日块（一周 = 5 个交易日）；
- 第 T 周组合的信息截止日 = 面板第 `(T-1)*5 − 1` 天（第 T−1 周最后一个交易日）；
- `signal_date` 落在面板索引 i 时，其分数最早可用于第 `i//5 + 2` 周——信号日之后的第一个调仓周，**无前视**；
- 同一周内出现两个 signal_date 时保留更晚者（节假日短周所致，更晚的信息截止日不引入前视）：141 个信号周去重后为 133 周（70,500 → 66,500 行）。

输出 `predictions_tree.parquet`：列 `pred_week, feature_dt, securityID, stacking`，共 66,500 行（133 周 × 500 只），覆盖第 **196~328 周——与线性版完全相同的周集合与回测窗口**。

## 3. 三版组合优化（周频调仓，参数与线性版完全一致）

### 3.1 共同设定

- **回测期**：2024-01-02 ~ 2026-10-09，第 196~328 周，133 个调仓周；
- **候选池**：每周取分数最高的 30 只股票（N_TOP = 30）；
- **分数 → 预期收益映射**：α = 分数 × σ_cs，σ_cs = 研发期（2020-2023 年）每周截面收益标准差的均值（本面板 σ_cs = 0.0605，与线性版相同）；
- **协方差矩阵**：过去 40 个交易日日收益；极端值处理（|日收益| > 0.2 置 0 + 每只股票 40 日窗口 MAD 去极值，倍数 3.0）后周频化 Σ_week = 5 × Σ_day，对角加 1e-8；
- **风险厌恶系数** δ = 2.5。

### 3.2 v1：四组合（portfolio_opt_v1_tree.py）

每周对 top-30 候选池直接构造四种组合：

| 组合 | 构造方式 |
|---|---|
| **BL组合** | 逆向优化 Π = δΣw_eq（w_eq = 1/30）；P = I，Q = 预测分，Ω = τ·diag(PΣPᵀ)，τ = 0.05；后验 μ_post → Markowitz（无卖空、个股权重 ≤ 0.1）；Σ 用**未处理**日收益 |
| **风险约束BL** | Σ 用**处理后**日收益；目标 = 夏普比率 − 0.2 × VaR(95%, 周频)，z = 1.645；s.t. w ≥ 0、Σw = 1、w ≤ 0.1 |
| **MV组合** | Σ 用处理后日收益；max αᵀw − (δ/2)wᵀΣw，s.t. w ≥ 0、Σw = 1、w ≤ 0.1 |
| **等权组合** | 各 1/30 |

输出 `portfolio_weights_v1_tree.parquet`（133 周 × 30 只，权重均值 1/30）。

### 3.3 v2：MV+约束组合（portfolio_opt_v2_tree.py）

- **选股信号平滑**：最近 4 周分数滚动均值（SMOOTH_K = 4，仅用过去值，无前视）取 top-30；
- **凸优化**（cvxpy + OSQP，失败退回等权）：

```
max  αᵀw − (δ/2) wᵀΣw − λ_ind‖Hᵀw − b‖² − λ_turn‖w − w_prev‖₁
s.t. w ≥ 0,  Σw = 1,  w ≤ 0.1
```

- α = 平滑分数 × σ_cs；Σ 用处理后日收益；
- **行业中性软约束** λ_ind = 0.5：惩罚组合行业权重与基准（申万一级）权重的平方偏离，**仅 2024-09-23（行业数据起点）起生效**（此前不加惩罚）；
- **换手惩罚** λ_turn = 0.002：w_prev = 上周权重按持有期收益漂移后对齐到本期候选池（新进池股票记 0），与回测换手口径一致。

输出 `portfolio_weights_v2_tree.parquet`（列：week, feature_dt, securityID, ind_w, indcon）。行业约束生效 98/133 周，生效周平均 |行业偏离| = 0.0292、最大 0.2415，剔除无行业信息个股 0 次。

### 3.4 v3：BL+约束组合（portfolio_opt_v3_tree.py）

与 v2 的唯一区别是预期收益换成 **BL 后验收益**（He & Litterman 1999，与锁定 BL 口径一致）：

```
Π = δΣw_eq,  P = I,  Q = 平滑分数 × σ_cs,  Ω = τ·diag(PΣPᵀ)（τ = 0.05）
μ_post = Π + τΣPᵀ(PτΣPᵀ + Ω)⁻¹(Q − PΠ)
```

Σ 用**未处理**日收益（锁定 BL 口径）；行业中性与换手惩罚与 v2 完全相同；硬约束 w ≥ 0、Σw = 1、w ≤ 0.1。输出 `portfolio_weights_v3_tree.parquet`（列含 blc_w, indcon）。行业约束生效 98/133 周，平均 |行业偏离| = 0.0293。

## 4. 统一回测口径（backtest_tree.py）

- **周收益**：第 T 周组合收益 = Σ w_i·(close[5T−1]/close[5(T−1)−1] − 1)，w_i 为第 T−1 周最后一天算出的权重；
- **指增产品净值** = 80% 中证A500全收益 + 20% 主动组合，周频再平衡；
- **交易成本**：主动组合扣单边 0.15%（打包佣金+印花税+冲击成本），按每周单边换手收取，首周建仓计一次；
- **单边换手**：调仓时 |w_{T+1} − w_T 按持有期漂移后| 的一半（只算买入侧）；产品口径换手 = 0.2 × 主动口径；年化 ×52；
- **管理费**：指增产品再扣年化 0.5%（按周折算 (1.005)^(1/52) − 1，对全部产品净值收取）；未扣托管费；
- **无风险利率**取 0；年化 ×52。

**对比结论：**

1. **BL+约束组合仍是两套分数下受约束组合中的最优**：树版年化超额 4.4%、IR 0.88、换手 4.0x、最大回撤 −13.0%（12 个组合中最浅）；线性版 4.5%、IR 1.04、换手 4.8x。80/20 口径下两版基本打平（线性版 IR 略高）；此前树版 9.0% 的领先（无上限时）部分来自集中持仓红利（最大单股权重中位数超过 50%），加 0.1 个股权重上限后两版收敛。线性版 v1 BL 产品超额最高（6.3%、IR 1.21），但换手 9.3x、无行业中性约束；
2. **MV+约束组合两版基本持平**：年化超额 3.8% vs 3.4%、IR 0.86 vs 0.85、换手 3.3x vs 3.7x，结论稳健；
3. **v1 组合加 0.1 上限后行为正常化**：树版 BL 组合产品超额 +1.2%（主动回撤从 −56% 收窄到 −31%），线性版 BL 6.3%（IR 1.21）；v1 组合换手高（7~9x）且无行业中性，两版风险约束BL 扣费后超额均约 0%（线性 +0.1%、树版 −0.3%）；
4. **共性**：两组分数下"MV+约束"与"BL+约束"都优于 v1 四组合（除线性版 BL 因超额最高但无约束而不作主推外），行业中性 + 换手惩罚 + 个股权重上限的组合层设计对分数来源稳健。

## 7. 结论与限制

- 树模型分数接同一组合优化管线后，**主推组合（BL+约束）产品口径年化超额 4.4%、信息比率 0.88、换手 4.0x、最大回撤 −13.0%**（12 个组合中最浅）；线性模型分数版 BL+约束为 4.5%、IR 1.04——80/20 口径下两版基本打平、线性版 IR 略高（此前树版 9.0% 的领先部分来自无上限时的集中持仓红利；线性版 v1 BL 产品超额 6.3%、IR 1.21 最高，但换手 9.3x 且无行业中性约束）。MV+约束版两者基本持平（3.8% / 0.86 vs 3.4% / 0.85）。
- 收益主要来自 2024–2025 年（2024 年 BL+约束年化 33.5%、2025 年等权 44.8%、MV+约束 44.6%）；2026 年（截至 10-09）市场下跌 9.3%，所有组合年化收益均为负——与"回测成绩靠 2024 年 + 组合层"的既有诊断一致。
- 口径与限制同线性版：开发股票池（幸存者偏差）、未复权价格面板、行业约束仅 2024-09-23 起生效、成本假设（单边 0.15% + 管理费 0.5%/年）为简化设定；树模型本身为研究阶段暂定版本，尚无独立样本外验证。
