# 外部线性模型分数版：组合优化与回测报告

> 本报告记录将**因子经线性模型训练后的预测分数**（队友仓库主候选：Corr 0.50 筛选 + Ridge 回归的样本外预测）接入本地组合优化与回测管线的全部步骤细节。所有代码与产物位于 `final/` 目录。

---

## 0. 总体流程

```
外部预测分数（周×股票，prediction_rank 0-1 百分位）
        │  prepare_external_scores.py（周频对齐 + 防前视映射）
        ▼
predictions_external.parquet（pred_week, feature_dt, securityID, stacking）
        │
        ├─ portfolio_opt_v1_external.py  →  v1 四组合：BL / 风险约束BL / MV / 等权
        ├─ portfolio_opt_v2_external.py  →  v2 MV+约束组合（行业中性 + 换手惩罚）
        └─ portfolio_opt_v3_external.py  →  v3 BL+约束组合（BL 后验 + 同 v2 约束）
        │
        ▼
backtest_external.py（六组合统一回测：周收益 → 换手 → 扣成本费用 → 指标 → 图）
        │
        ▼
指标表 PNG/CSV、净值图、超额图、月度胜率图、分年度业绩表、同业对比图、换手柱状图
```

## 2. 预测分数准备（prepare_external_scores.py）

**周编号映射（关键口径，三个优化脚本与回测脚本共用）：**

- 价格面板第 i 个交易日属于第 `i//5+1` 个 5 日块（一周 = 5 个交易日）；
- 本地脚本中第 T 周组合的信息截止日 = 面板第 `(T-1)*5 - 1` 天（即第 T-1 周最后一个交易日）；
- 外部 `signal_date` 落在面板索引 i 时，其分数最早可用于第 `i//5 + 2` 周——即信号日之后的第一个调仓周，**无前视**；
- 若同一周内出现两个 signal_date，保留更晚者（更晚的信息截止日不会引入前视）。

输出 `predictions_external.parquet`：列 `pred_week, feature_dt, securityID, stacking`，共 66,500 行（133 周 × 500 只），覆盖第 196~328 周。

## 3. 三版组合优化（周频调仓）

### 3.1 共同设定

- **回测期**：2024-01-02 ~ 2026-10-09，对应第 196~328 周，共 133 个调仓周；
- **候选池**：每周取分数最高的 30 只股票（N_TOP = 30，沿用锁定设计）；
- **分数 → 预期收益映射**：α = 分数 × σ_cs，其中 σ_cs = 研发期（2020-2023 年）每周截面收益标准差的均值（把 0-1 排名分映射回周频预期收益量纲）；
- **协方差矩阵**：过去 40 个交易日日收益，先做极端值处理（|日收益| > 0.2 置 0，再按每只股票 40 日窗口做中位数 MAD 去极值，倍数 3.0），再周频化 Σ_week = 5 × Σ_day，对角加 1e-8 保证正定；
- **风险厌恶系数** δ = 2.5（沿用锁定设计）。

### 3.2 v1：四组合（portfolio_opt_v1_external.py）

每周对 top-30 候选池直接构造四种组合：

| 组合 | 构造方式 |
|---|---|
| **BL组合** | 逆向优化 Π = δΣw_eq（w_eq = 1/30）；观点 P = I（每个股票的"观点"即其自身预测分），Q = 预测分；观点不确定性 Ω = τ·diag(PΣPᵀ)，τ = 0.05；后验收益 μ_post → Markowitz 最大化（无卖空、个股权重 ≤ 0.1）；Σ 用**未处理**日收益 |
| **风险约束BL** | Σ 用**处理后**日收益；目标函数 = 夏普比率 − 0.2 × VaR(95%, 周频)，VaR 分位数 z = 1.645；s.t. w ≥ 0、Σw = 1、w ≤ 0.1 |
| **MV组合** | Σ 用处理后日收益；max αᵀw − (δ/2)wᵀΣw，s.t. w ≥ 0、Σw = 1、个股权重 ≤ 0.1 |
| **等权组合** | 各 1/30 |

输出 `portfolio_weights_v1_external.parquet`（列：week, feature_dt, securityID, bl_w, blrisk_w, mv_w, eq_w）。

### 3.3 v2：MV+约束组合（portfolio_opt_v2_external.py）

- **选股信号平滑**：用最近 4 周分数的滚动均值（SMOOTH_K = 4，滚动仅用过去值，无前视）取 top-30。原因：周频分数噪声大，每周直接 top-30 平均要换 22 只股票；平滑后换手从 43.4x 降到 16.5x，且收益更高；
- **目标函数**（cvxpy + OSQP 凸优化求解，失败则退回等权）：

```
max  αᵀw − (δ/2) wᵀΣw − λ_ind‖Hᵀw − b‖² − λ_turn‖w − w_prev‖₁
s.t. w ≥ 0,  Σw = 1,  w ≤ 0.1
```

- **行业中性软约束**：λ_ind = 0.5，H 为候选池股票的申万一级行业 one-hot 矩阵，b 为基准行业权重（对全 A 股按行业加权求和并归一）。惩罚组合行业权重与基准的平方偏离。行业数据自 2024-09-23 起可用，此前不加行业惩罚（λ 视为 0）；
- **换手惩罚**：λ_turn = 0.002，w_prev = 上周权重按持有期收益漂移后对齐到本期候选池（新进池股票记 0）：

```
w1h = w1 × (1 + r_i) / (1 + r_port)
```

  （与回测的换手口径完全一致）；
- 输出 `portfolio_weights_v2_external.parquet` 与行业偏离检查表 `industry_deviation_v2_external.parquet`。

### 3.4 v3：BL+约束组合（portfolio_opt_v3_external.py）

与 v2 的**唯一区别**是预期收益的构造方式——把"分数 × σ_cs 直接用"换成 Black-Litterman 后验收益（He & Litterman 1999）：

```
Π = δΣw_eq（逆向优化，w_eq = 1/30）
P = I，Q = 平滑分数 × σ_cs
Ω = τ·diag(PΣPᵀ)，τ = 0.05
μ_post = Π + τΣPᵀ(PτΣPᵀ + Ω)⁻¹(Q − PΠ)
```

- Σ 用**未处理**日收益（与锁定版 BL 口径一致）；
- 硬约束为 w ≥ 0、Σw = 1、w ≤ 0.1；
- 行业中性软约束（λ_ind = 0.5）与换手惩罚（λ_turn = 0.002）与 v2 完全相同，便于与 v2 对比"BL 后验 vs 直接 α"的差异。

### 3.5 三版参数汇总

| 参数 | 取值 | 说明 |
|---|---|---|
| N_TOP | 30 | 每周候选池股票数 |
| COV_DAYS | 40 | 协方差估计窗口（交易日） |
| DELTA | 2.5 | 风险厌恶系数 |
| TAU | 0.05 | BL 观点不确定性系数 |
| CAP | 0.1 | 个股权重上限（除等权外全部组合） |
| EXTREME / MAD_K | 0.2 / 3.0 | 日收益极端值处理 |
| VAAR_Z / VAAR_LAMBDA | 1.645 / 0.2 | 风险约束BL 的 VaR 惩罚 |
| SMOOTH_K | 4 | v2/v3 选股信号平滑窗口 |
| LAMBDA_IND | 0.5 | 行业中性软约束惩罚系数 |
| LAMBDA_TURN | 0.002 | 换手惩罚系数 |
| INDCON_START | 2024-09-23 | 行业约束生效起点（数据起点） |

## 4. 统一回测（backtest_external.py）

### 4.1 周收益计算

- 第 T 周组合收益：r_T = Σ w_i × (close[5T−1] / close[5(T−1)−1] − 1)，其中权重 w_i 是第 T−1 周最后一个交易日（信息截止日）解出的；
- 指数周收益按与个股完全相同的交易日对齐（缺失交易日向前填充）；
- 回测窗口：第 196~328 周，共 133 周，2024-01-15 ~ 2026-10-09。

### 4.2 指增产品口径（汇报口径）

```
r_prod = 0.8 × r_idx + 0.2 × r_active
```

即 80% 中证A500全收益 + 20% 主动组合，**周频再平衡**。产品超额 = 0.2 × 主动超额。主动组合是中间结果，正式汇报用产品口径。

### 4.3 换手率（单边、漂移调整）

每次调仓只算**买入侧**（对称的卖出侧不计）：

```
w1h = w_T × (1 + r_i) / (1 + r_p)          # 上周权重按持有期收益自然漂移
t   = 0.5 × Σ|w_{T+1} − w1h|               # 本期单边换手
t₀  = 0.5 × Σ|w₀|                          # 首周建仓（空仓→满仓）也计一次
年化换手 = Σt × 52 / 周数
产品口径换手 = 0.2 × 主动换手
```

### 4.4 交易成本与管理费

| 项目 | 取值 | 收取方式 |
|---|---|---|
| 单边交易成本 | 0.15%（打包：佣金 + 印花税 + 冲击成本） | r_net = r − 0.0015 × turn，在调仓周收取 |
| 管理费 | 0.5% / 年 | 周化 FEE_W = (1.005)^(1/52) − 1，对产品全部净值收取：r_prod_net = 0.8×r_idx + 0.2×r_net − FEE_W |
| 托管费 | 未扣 | — |
| 无风险利率 | 0 | 夏普比率计算用 |

### 4.5 业绩指标

- 全期指标：累计收益 Π(1+r) − 1；年化收益 (1+total)^(52/n) − 1；年化波动 std × √52；夏普 (mean − RF/52) / std × √52；最大回撤 = 净值曲线相对历史高点的最大跌幅；
- 超额指标：累计超额 Π(1+rp)/Π(1+rb) − 1；年化超额；跟踪误差 TE = std(rp − rb) × √52；信息比率 IR = mean(rp − rb) × 52 / TE；周胜率 = P(周超额 > 0)。
