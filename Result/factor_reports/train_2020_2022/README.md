# 2020–2022 训练集因子质量报告

本目录保留最初的因子质量报告，不包含事后翻转因子方向的双向汇总。

| 文件 | 内容 |
|---|---|
| `factor_quality_report.html` | 可离线打开的交互报告；包含因子分布、收益风险、IC 换手及单因子逐周图 |
| `factor_summary.csv` | 344 个因子的完整汇总指标 |
| `factor_issues.csv` | 无效截面和缺失退出价格的因子日期清单 |
| `factor_quality_report_2020_2022.zip` | 上述报告与表格的单文件下载包，含本说明 |

指标由 `python Code/build_factor_quality_report.py` 从本地因子矩阵与行情重新生成。信号在每周最后一个交易日收盘后形成，下一交易日收盘建仓，持有至下次调仓执行日收盘；所有信号日及退出日均在 2020–2022 年内。因子值在每期股票截面按平均秩映射至 0–1；多头和空头分别占 50% 资金，权重与距离中位排名的距离成正比。成本为全部调仓权重绝对变化之和乘以 20 bp。

这些是训练集内描述性统计。历史成分股、同期基准与行业数据尚未提供；股价未复权，借券费和融资费未计入。报告不得作为样本外模型选择结果。股票级原始数据、因子矩阵和逐周中间表均未收入 Git。
